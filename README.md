A fast, light frontend for make.fun: the live bounty board (live pot, entry fee, time left, entries), a bounty's page (rewards table with the live pot, dates, rules), its leaderboard, and an account's public profile — each reachable by a link and by its own URL. Static files only (ES modules + CSS, no build step), reading make.fun's public API alone. API answers are cached and ETag-revalidated, lists are paginated, and the countdowns tick in place without rebuilding the page.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
